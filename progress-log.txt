📌 SAVED TECHNICAL LESSONS (DO NOT REPEAT)
═══════════════════════════════════════════════════════════════

1. After adding new locale file:
   Ctrl+C → Remove-Item -Recurse -Force .next → npm run dev

2. npx tsc --noEmit = FINAL verdict
   VS Code Problems = fast helper (may be wrong)

3. Restart TS Server after any prisma migrate:
   Ctrl+Shift+P → TypeScript: Restart TS Server

4. MISSING_MESSAGE from next-intl:
   Add key in all 5 files → clear .next → restart

5. HTML5 native validation is English-only:
   Add noValidate on <form> to show Zod messages

6. Prisma + Vercel:
   - prisma-client-js (not prisma-client)
   - binaryTargets: ["native", "rhel-openssl-3.0.x"]
   - --webpack in dev + build
   - DATABASE_URL without -pooler

7. Server Actions + i18n:
   - getTranslations("Errors") inside action
   - Schema Factory pattern: createXxxSchema(t)

8. set-state-in-effect ESLint Rule:
   - No useEffect with sync setState
   - Use useState(() => initialValue) for init-only

9. Metadata in layout:
   - Use generateMetadata() for translations
   - export const metadata = static, cannot be translated

10. Image Picker Auto-Generated Pattern:
    - scripts/generate-local-images.ts reads public/images/
    - Runs via predev + prebuild hooks
    - Reason: Vercel can't read public/ at request time
