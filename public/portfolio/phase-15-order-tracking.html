Phase 15 · Order Tracking & Email Automation

Post-Purchase Experience

Complete the customer lifecycle by adding a secure, URL-driven order tracking page and automated, beautifully branded email receipts triggered directly from the Stripe webhook.

Next.js Server ComponentsURL State React EmailResendZod

1 Overview

Goal: Close the loop on the food delivery flow. After a customer pays, they need a way to track their delivery without creating an account. Furthermore, they need an immediate, professional receipt in their inbox.

Key Deliverables

  • Smart Tracking Page: A single search form (/track-order) that accepts either an Order ID or an Email.
  • Visual Timeline: A responsive, step-by-step progress indicator for the order status.
  • Privacy-First Design: Searching by email reveals only a summary list, never the full address or phone number.
  • Automated Emails: Integration of React Email and Resend to send order confirmations directly from the Stripe Webhook.
  • Robust Validation: Zod schemas to prevent invalid database queries.

2 Tracking UI & URL State

To make the tracking page shareable and refresh-safe, we avoided client-side useState for search results. Instead, the page relies entirely on URL State (?id=... or ?email=...).

The page is a Server Component that reads the searchParams, classifies the input, and fetches the data server-side.

3 Privacy-First Architecture

If a user searches by email, returning full order details is a severe security risk (anyone could type admin@gmail.com and see their home address).

The Privacy Rule
  • Search by Order ID: Returns full details (Address, Phone, Items, Timeline).
  • Search by Email: Returns a summary list (Date, Total, Status) without sensitive PII.

We enforced this at the database query level using Prisma select to ensure sensitive fields are never even fetched from the DB during an email search.

// src/lib/services/orderTracking.ts
export async function getTrackedOrdersByEmail(email: string) {
  return await prisma.order.findMany({
    where: { guestEmail: { equals: email, mode: "insensitive" } },
    select: {
      id: true,
      createdAt: true,
      status: true,
      totalAmount: true,
      // Notice: NO deliveryAddress, NO guestPhone
    },
  });
}

4 Email Automation

We integrated Resend and React Email to dispatch a beautifully branded receipt the moment a payment succeeds.

Webhook Integration

The email is triggered inside the Stripe Webhook after the database transaction successfully updates the order status to PAID. We wrapped the email dispatch in a try/catch block so that if Resend's API goes down, it doesn't fail the Stripe webhook and cause Stripe to retry the payment.

// src/app/api/webhooks/stripe/route.ts
await prisma.$transaction(async (tx) => {
  // 1. Update order to PAID
  // 2. Deduct stock
});

// 3. Send email (Outside transaction)
try {
  await sendOrderConfirmation({
    to: existingOrder.guestEmail,
    guestName: existingOrder.guestName,
    orderId: existingOrder.id,
    items: existingOrder.items.map(i => ({
      name: i.menuItem.name,
      quantity: i.quantity,
      priceAtOrder: i.priceAtOrder,
    })),
    // ...
  });
} catch (error) {
  console.error("Email failed, but payment succeeded:", error);
}

5 Robust Validation & i18n

To prevent Prisma from crashing when a user types random text into the search bar, we intercept the input with a custom Zod validation schema.

// src/lib/validations/orderTracking.ts
const CUID_REGEX = /^c[a-z0-9]{24}$/i;

export function classifyQuery(raw: string): ClassifiedQuery {
  const value = raw.trim();
  if (CUID_REGEX.test(value)) return { type: "id", value };
  if (value.includes("@")) return { type: "email", value: value.toLowerCase() };
  return { type: "invalid", value };
}

Internationalization (i18n): The tracking page, the visual timeline, and the email receipts are fully translated across all 6 supported locales (en, ar, fr, de, it, zh), including RTL support for the Arabic email template.

6 Engineering Lessons

  • URL State is superior for searches. Moving search parameters out of React state and into the URL (?id=) means users can refresh, bookmark, and share their tracking link directly from the email without losing the result.
  • Side-Effects & Transactions. Never send emails inside a Prisma transaction. If the email API times out, the transaction rolls back, and you have a "paid" customer with a "pending" order in your database. Always dispatch emails after the transaction resolves.
  • Resend Free Tier Limits. During testing, we learned that the free tier of Resend only allows sending emails to the specific email address you registered the account with, preventing spam. Production requires verifying a custom domain.
  • Component purity. Extracting the OrderTimeline into a "dumb" component that receives translation strings as props makes it infinitely reusable in both Server Components and Client Components (like modals).
